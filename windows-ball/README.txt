X 粉丝增长悬浮球
- 双击 start_fan_ball.vbs 启动（无黑窗）；或运行 launch_ball.ps1 / restart_ball.ps1
- 左键拖动；悬停弹出关注列表（打开 X / 上供）；双击打开增长面板；右键菜单可退出
- 半透明玻璃胶囊 + 官方 X 标；右侧显示粉丝数与「今日 +N」
- 状态文件: %LOCALAPPDATA%\XFanGrowth\state.json（含 daily 今日新增）

依赖 (pip)
- pillow（必需）
- 滚动条为内置 ThinScrollbar（无需 customtkinter）；如需可自行 pip 安装但不强制

安装依赖:
  py -3 -m pip install pillow -q
